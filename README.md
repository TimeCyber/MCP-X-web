## 🌟 核心功能

### 🎬 1. AI 视频工作室（Video Studio）

> 支持：千问 / 即梦 / 可灵 / 海螺 / **Seedance 2.0** / Veo3 / Runway 等

从剧本到成片的全流程 AI 视频制作：

| 功能 | 说明 |
|------|------|
| **故事板模式** | **GPT Image 2** 生成多分镜故事板 → **Seedance 2.0** 参考图生视频，角色/场景一致、分镜可控，**推荐高质量创作首选** |
| 剧本解析 | AI 自动分析剧本，提取角色、场景、故事段落 |
| 分镜生成 | 智能生成专业分镜列表，含镜头运动、景别、关键帧 |
| 角色 & 场景 | AI 生成角色定妆照和场景概念图，作为故事板与视频参考 |
| 视频生成 | 文生视频 / 图生视频 / 首尾帧插值 / **参考图模式** |
| 一键导出 | 浏览器端合并导出视频片段 |
| 资源库 | IndexedDB 本地存储，角色/场景/视频资源复用 |

### 💬 2. AI 对话系统

> 支持：GPT / Gemini / DeepSeek / Kimi / 千问 等

- 多模型切换 · SSE 流式响应 · MCP 工具调用
- 网络搜索集成 · Agent 工作流人工介入 · 文件上传对话
- 企业知识库 RAG 增强检索

### 💻 3. 前端应用构建（App Builder）

> 类似 Bolt / Loveable 的 AI 前端构建体验

- **一键生成网页**：自然语言描述需求，AI 快速生成完整网页并实时预览
- 对话式开发：支持多轮迭代修改布局、样式与交互
- 多框架：HTML / React / Vue / 静态网站
- 实时预览 · 可视化编辑 · 一键部署 · 代码下载 · HTML 导出 PPT

### 🖼️ 4. AI 图像编辑器

> 支持：千问 / Seed / Nano Banana / **GPT Image 2** / Nano Banana Pro 4K 等

- **GPT Image 2**：平台现阶段最强图像模型，文生图/图生图质量领先
- 文生图 · 图生图 · 蒙版局部编辑
- 图生视频 · @ 符号参考生视频
- 多模型选择 · 多尺寸设置

### 🔧 5. MCP 服务市场 & Agent 市场

- **1000+** MCP 工具，按分类浏览、搜索、一键配置

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装 & 运行

```bash
# 克隆项目
git clone https://github.com/TimeCyber/MCP-X-web.git
cd MCP-X-web

# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

### 配置

在 `src/config/index.ts` 中修改 API 地址：

```typescript
const apiBaseUrl = import.meta.env.VITE_API_BASE_URL ||
  (import.meta.env.PROD ? 'https://www.mcp-x.com/prod-api' : 'https://www.mcp-x.com/prod-api');
```
